## Project Summary
This project is a centralized database for a theme park designed to integrate ticketing,
hotel reservation systems, loyalty programs, and ride operations. By consolidating all customer
and operational data into one platform, it enables staff and management to efficiently monitor
guest activity, apply rate modifiers, validate ride access, and track maintenance.
